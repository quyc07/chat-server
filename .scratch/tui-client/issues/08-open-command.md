# 08: `/open` 开始新会话

**What to build:** 用一条命令打开跟任何人的对话，包括从未聊过的人——否则那些人永远进不了会话列表，也就永远够不着。会话不需要预先在服务端登记，发出第一条消息后它自己就出现了。

**Blocked by:** 04 发送消息

**Status:** ready-for-agent

- [ ] `/open <名字>` 能按模糊匹配找到用户并打开会话
- [ ] 有多个匹配结果时让用户选择，不静默取第一个
- [ ] 找不到用户时给出明确提示
- [ ] 对从未聊过的人打开的是空会话，可以正常发送第一条消息
- [ ] 发出第一条消息后，该会话出现在会话列表里
