# 02: 账号入口 + 会话列表

**What to build:** 打开客户端就能登录或注册，登录后立刻看到自己的会话列表——按最近消息倒序，每条带对方名字、最后一条消息摘要、时间和未读数。令牌只活在内存里，长时间挂着时自动续登，不把凭据写到磁盘上。

**Blocked by:** 01 服务端会话列表排序与可测性

**Status:** resolved

- [x] 启动后显示登录页，可输入用户名和密码登录
- [x] 登录页可切到注册，注册成功后直接进入已登录状态
- [x] 登录失败时状态行显示服务端返回的具体错误文本（去掉外层 JSON 引号），不是笼统的"登录失败"
- [x] 密码只存在于进程内存，配置文件、日志、磁盘上都不出现
- [x] 令牌在有效期内于第 50 分钟被主动替换，替换后后续请求仍然成功
- [x] 登录成功后显示会话列表，按最近消息时间倒序
- [x] 每个条目显示对方名字、最后一条消息摘要、时间和未读数
- [x] "全部未读"用区别于数字的标记呈现
- [x] 服务端不可达时状态行显示明确的连接错误，程序不退出
- [x] 窗口缩小到任意尺寸时布局降级而不崩溃
- [x] 退出时调用登出接口，本地令牌被清空
