# 05: SSE 实时接收

**What to build:** 登录后客户端维持一条推送连接，对方发来的消息立刻出现在界面上。正在看的会话直接追加；没在看的会话，列表里对应条目的未读数加一并跳到顶部。

**Blocked by:** 03 打开会话 + 历史消息流

**Status:** ready-for-agent

- [ ] 登录后自动建立推送连接，鉴权走查询参数（浏览器式客户端加不了 header）
- [ ] 对方发来的消息在当前打开的会话里立刻出现
- [ ] 当前未打开的会话收到消息时，列表里该条目未读 +1 并移到顶部
- [ ] 心跳事件不进入消息流
- [ ] 推送里三层嵌套的消息结构与历史接口的扁平结构归一到同一个消息类型
- [ ] 收到来自从未出现过的会话的消息时，列表能新增该条目（对方名字经查询补全）
