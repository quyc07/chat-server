# 03: 打开会话 + 历史消息流

**What to build:** 在会话列表里选中一个人，右侧立刻显示这段对话的历史消息，自己和对方说的话在视觉上分得开，长消息和中文都能正确换行。

**Blocked by:** 02 账号入口 + 会话列表

**Status:** ready-for-agent

- [ ] 在会话列表里选中一条，右侧显示该会话的历史消息
- [ ] 自己发的和对方发的消息视觉上可区分
- [ ] 每条消息显示发送时间
- [ ] 长消息和中文按可用宽度正确换行，不截断、不溢出
- [ ] 历史条数达到后端上限时仍能正常渲染和滚动
- [ ] 切换到另一个会话时消息流整体替换，不残留上一个会话的消息
