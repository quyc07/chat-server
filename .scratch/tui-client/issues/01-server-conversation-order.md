# 01: 服务端会话列表排序与可测性

**What to build:** 会话列表接口返回的顺序就是真实顺序——按每个会话最近一条消息倒序排列，分页之后依然正确。同时让整个服务端路由器能在临时目录里启动，使这条行为可以被自动化测试证明，而不是靠手工点。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 会话列表返回的条目按最近消息时间倒序，相同的底层数据两次请求顺序稳定
- [ ] 分页上限从 10 放宽到 50，且不影响其他接口（这个分页参数目前只有会话列表在用）
- [ ] 整个路由器可以在临时目录启动，不读写仓库里的数据目录
- [ ] 有一条集成测试：种入三条时间乱序的已读位点，断言返回顺序正确
- [ ] 有会话时，列表条目的既有字段（名字、摘要、时间、未读数）不回归
