# 06: 断流检测与重连补拉

**What to build:** 服务端在慢客户端落后时会静默掐断推送，客户端察觉不到任何收尾信号。这条让客户端靠心跳判断自己已经断线、明确告诉用户、然后自己连回去，并把断线期间错过的消息补回来——不丢、也不重复。

**Blocked by:** 05 SSE 实时接收

**Status:** ready-for-agent

- [ ] 14 秒（三个心跳周期）收不到心跳即判定断流，状态行显示"连接断开，正在重连"
- [ ] 断流后自动重连，不需要用户任何操作
- [ ] 重连成功后补拉当前打开会话的历史，断线期间的消息被补回
- [ ] 补拉结果按消息 id 去重，不产生重复条目
- [ ] 重连后会话列表被刷新，未读数准确
- [ ] 断线期间仍能正常发送消息（发送走独立请求，不依赖推送连接）
